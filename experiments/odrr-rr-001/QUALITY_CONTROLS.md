# Outcome-Neutral Quality Controls — ODRR-RR-001

The confirmatory task must demonstrate that it can distinguish **mere rotation** from **genuine rearrangement** before any target-versus-control result is allowed to carry evidentiary weight.

## QC-ROT-STABLE

Use a simple, deliberately constructed pattern with highly stable internal relations. Show the same pattern at several orientations without rearranging its parts.

Expected study-level response:
- median `mere_rotation >= 7`;
- median `grouping_change <= 4`.

Failure means the rating task is not reliably recognizing an obvious case of stable organization under rotation.

## QC-REARRANGED

Use the same primitive elements but spatially rearrange their internal relations between presentations.

Expected study-level response:
- median `grouping_change >= 7`.

Failure means the task is not reliably detecting an obvious relational change.

## Gate

Both study-level quality controls must pass before the primary ODRR result can receive `SURVIVED`, `EQUIVALENT`, or `CONTROL_ADVANTAGE` classification.

If either fails:

`INCONCLUSIVE — TASK/MEASUREMENT VALIDITY FAILURE`

This outcome-neutral gate is intentionally capable of voiding an apparently favorable target/control result.

## Participant checks

Three instructed-response or task-understanding checks are embedded separately. These checks do not contain target/control material. Failing at least two is a predeclared participant exclusion.
