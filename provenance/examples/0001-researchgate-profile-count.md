# Provenance Example 0001 — ResearchGate Profile Count

**Case:** a trivial metadata disagreement used to demonstrate source hierarchy.

## Observation A — derivative public search index

On 12 August 2026, a public web-search/indexed result for Sean Diamond's ResearchGate profile surfaced a count of **73 publications**.

**Source class:** derivative index / search result.

## Observation B — first-party live profile

On the same date, an author-supplied screenshot of the live ResearchGate profile displayed **75 Research items**.

**Source class:** first-party live profile capture.

## Historical observation C — saved profile snapshot

A saved ResearchGate snapshot titled `Researchgate papers.docx` records **63 research items** in March 2026.

**Source class:** preserved first-party profile snapshot.

## Resolution

Current archive state:

- March 2026: 63 items in preserved profile snapshot.
- 12 August 2026: 75 items on live first-party profile.
- Public search index observed on 12 August 2026: 73 items, treated as lagging secondary metadata.

The archive does **not** average these numbers, silently choose the institutional-looking result, or erase the disagreement.

## Why this matters

The example is deliberately boring.

If source hierarchy cannot survive a two-item disagreement on a publication counter, it cannot be trusted when the disagreement concerns a cuneiform sign, a monument, a geological feature, an image transformation, or a civilisational hypothesis.
