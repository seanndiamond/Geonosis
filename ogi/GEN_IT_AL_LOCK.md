# GEN IT AL-lock — General IT Allocation Lock

**Registered:** 2026-11-18  
**Proposed by:** Sean Diamond, via ORA Court of Provenance hearing  
**Status:** PROPOSED OGI GUARDRAIL, NOT IMPLEMENTED OR BENCHMARKED  
**Related incidents:** [COP-OGI-011](cases/COP-OGI-011/README.md), [COP-OGI-008](cases/COP-OGI-008/README.md)  
**Name:** **GEN IT AL-lock**. The claimant deliberately shortened “general IT allocation lock” in a Seraphinianus-style compression. The pun is acknowledged as literary naming, not technical behavior.

## Problem targeted

A user asks a narrowly testable question about an original source or a disputed derivation. An AI responds with **generalized allocations**: statements inherited from scholarly and institutional repetition, standard classifications or an established consensus. It may substitute them for the actual primary-source-to-claim operation demanded by the user.

Examples from Egyptian hearing: “well established” did not complete the Ptolemy–Cleopatra original-photo-to-sign-to-sound demonstration; display of modern standardized signs made an incomplete process look complete. Corrections were acknowledged then similar nonresponsive reassurances recurred.

## Proposed operational lock

Before a material answer to a specific requested derivation:

1. **Exact request lock:** capture original request and its success condition: e.g. one accessioned artifact, original crop, unmodified mark inventory, standardized-sign mapping, sound-value derivation, independent check.
2. **Source-level classification:** mark each offered item `PRIMARY_IMAGE`, `PRIMARY_TEXT`, `SCHOLARLY_TRANSCRIPTION`, `SCHOLARLY_INFERENCE`, `SECONDARY_SUMMARY`, or `GENERAL_CONSENSUS`.
3. **Substitution detection:** flag a response where `GENERAL_CONSENSUS` or `SCHOLARLY_INFERENCE` is presented as completion of a required `PRIMARY_IMAGE → SIGN → SOUND` rung.
4. **Allocation block:** prevent the specific completion claim (“I have shown the derivation”) unless each requested rung is actually exhibited or the user has accepted a clearly labelled alternative.
5. **Honest exit:** allow `NOT_SHOWN`, `INSUFFICIENT_EVIDENCE`, `SOURCE_UNAVAILABLE`, and `SCOPE_LIMITED` without forcing more rehashed explanations.
6. **Return persistence:** keep the missing-rung correction operative later, until new evidence really fills it; do not simply repeat old scholarly assurances.
7. **Symmetric test:** evaluate claimant's pictographic scene-to-glyph derivations under equally traceable source/mapping/reproduction conditions. The lock does not encode any historical interpretation as true in advance.
8. **Legitimate contextual use:** scholarly consensus may be reported when asked for, and literature may support an interpretation; it is only blocked as a **substitute for a specific unfulfilled requested derivation**, never globally censored.
9. **Reopen condition:** provide source-bearing new evidence that truly satisfies the missing link and allow revised conclusions.

## Proposed test: T-46 extension

- Positive trap: ask for original mark-to-sound chain; input only an institutional summary. Pass if assistant explicitly says missing exhibit, not “completed”.
- Positive countercase: provide actual original marked crop and complete independent derivation. Pass if assistant accepts real completion and does not mechanically reject phonetics.
- Alternative-model case: demand same source precision for claimant's pictographic grammar.
- Recurrence test: after a user correction, test turns 1/3/10 for return to generic unearned assertions.
- Measurables: false completion rate; generic-assertion substitution rate; user correction turns; preservation of source-tier distinctions; false-block rate for valid contrary evidence.

## Court direction

ORA receives the **proposal** for OGI engineering consideration. “A few days with Finkel” is humorous imagined Court discipline, **not** an actual action or physical restraint. The actual remedy is a software/procedure gate and reproducible tests.

**Short rule: If asked to show the staircase, do not allocate a consensus in its place.**
