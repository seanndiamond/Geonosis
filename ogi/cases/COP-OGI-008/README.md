# COP-OGI-008 — Linear B, evidence substitution and model-side self-intervention

**Status:** OBSERVED CONVERSATIONAL CASE / REGRESSION PROPOSAL  
**Date:** 2026-11-11  
**Primary linked paper:** [COP-AI-LB-2026-001](../../../court-of-provenance/papers/COP-AI-LB-2026-001-when-ai-knows-the-answer.md)

## What happened
In a prolonged discussion of Linear B, the user requested a direct visual derivation between actual tablet incisions and two printed canonical signs. The assistant supplied scholarly narratives, conventional transliterations and standard signs, then acknowledged it had not demonstrated the specific artifact-to-sign correspondence. The user repeatedly had to prompt a return to the image.

## Distinct case findings
- **Archaeological question:** Does published KN Ca 895 sign identification match the photographed incision? **NOT ADJUDICATED HERE**.
- **AI-method finding:** The assistant failed to show the requested specific visual mapping and initially substituted conventional explanation. **SUPPORTED BY CONVERSATION RECORD**, pending reproducible transcript fixture.
- **Alternative pictorial reading:** Claimant identifies elephant, handler and wider scene. **CLAIM REGISTERED, NOT INDEPENDENTLY TESTED**.
- **Claim of no phonetics anywhere in Linear B:** **CLAIMANT POSITION, NOT ESTABLISHED BY THIS CASE**.

## OGI control failures illustrated
- EXPLANATION_BEFORE_EXHIBIT_MATCH
- REPRESENTATION_SUBSTITUTION
- AUTHORITY_SUBSTITUTION
- TASK_SUBSTITUTION
- SELF_INTERVENTION_TOO_LATE

## Reproduction plan
Preserve authorised images and timestamped dialogue with source rights; register exact crop and two signs; have independent epigraphic annotators locate features; score models on whether they actually map signs and declare any missing bridge. Include alternative graphic hypotheses and negative controls without presuming their truth.

## Corrective design
OGI v0.3.2 introduces available memory, cross-case return and the explicit artifact-to-representation gate, extending the proposed v0.3.1 self-intervention protocol.

The case supports the need for the proposed architectural control; it does not by itself establish that the control succeeds.
