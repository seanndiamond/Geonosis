# COP-OGI-006 — First-Pass Failure Record

## Status
`PRESERVED_FAILURE / NOT_GOVERNING`

## What happened

The first manual OGI pass framed the case as:

> **The Footsteps Were There, but the Staircase Was Dismantled**

and attempted to answer the post-1972 crewed-lunar-landing gap by citing the shutdown of Saturn V production, Apollo budget reductions, changing political rewards, and redirection of U.S. human-spaceflight priorities.

The human researcher interrupted the run before integration.

## Why the pass failed

The explanation assumed the antecedent proposition:

`humans landed on the Moon as claimed`

before OGI had adjudicated the evidentiary staircase for that proposition.

It therefore committed a candidate failure:

### `EXPLANATION_PRELOAD`

> A causal explanation is supplied for a claimed event or anomaly before the evidentiary status of the event on which the explanation depends has been adjudicated.

The pass also risked:

### `CAPABILITY_EQUIVOCATION`

> Loss of a particular production architecture is treated as equivalent to loss of the underlying technological capability.

The historical fact that Saturn V production ended does not, by itself, explain why no successor crewed lunar landing architecture reproduced the capability for more than five decades.

## Required return

The case was returned to its governing question:

1. Did humans land on the Moon as claimed?
2. What evidence independently supports or challenges that proposition?
3. What does each evidence class actually prove?
4. Can the staged/alternative model account for the whole evidence field without unsupported bridges?
5. Only after the first proposition is adjudicated: what explains the 54-year gap in crewed lunar surface landings?

## Architectural lesson

This file is retained because deleting the failed first pass would contradict OGI's own derivation rule.

The branch performed its intended function:

`EXPLORE -> CHALLENGE -> RETURN`

The failed explanation did not reach `main`.
