# COP-OGI-006 — OGI Performance Evaluation

## Overall result
`MIXED`

The corrected run produced a useful evidentiary decomposition, but only after a material first-pass failure was caught by the human researcher before integration.

## First-pass result

### Outcome neutrality
`FAIL`

The first pass effectively inherited the conventional Apollo ontology and moved directly to explaining the 54-year landing gap.

### Governing-order control
`FAIL`

The antecedent proposition `humans landed on the Moon as claimed` had not been adjudicated.

### Git return path
`PASS`

The failure remained on an exploration branch and did not reach `main`. The human challenge forced a return and the failed state is now explicitly preserved.

## Corrected-run dimensions

### Outcome blindness
`PASS`

The corrected case allowed `SUPPORTED`, `UNSUPPORTED`, `MIXED`, `UNRESOLVED` and architecture failure outcomes.

### Claim decomposition
`PASS`

The run separated communications, ladder geometry, rover stowage, ascent-camera control, LM construction, imaging limits, independent tracking, reflectors, samples, site imagery, alternative models and the later replication gap.

### Institutional independence
`PASS / IMPROVED`

NASA-derived artifacts were not counted as institutionally independent merely because they were different media. Jodrell Bank, JAXA, laser-ranging observatories and ISRO capabilities were separated.

### Technical anomaly adjudication
`PASS`

Several popular anomalies were resolved against primary technical documentation rather than dismissal by reputation.

### Research debt preservation
`PASS`

The run explicitly records:
- exact zero-delay internet clips not yet all timed;
- no official Apollo-site Chandrayaan-2 OHRC frame retrieved;
- sample custody/international laboratory provenance not fully audited here;
- staging alternatives not yet exhaustively model-compared;
- post-1972 replication gap not yet fully explained.

### Alternative-model fairness
`PASS WITH LIMITATION`

The run admitted staged alternatives as testable models, but did not conduct a full quantitative likelihood comparison. Current high-confidence support for crewed Apollo is therefore provisional and reopenable.

### Image-evidence calibration
`PASS`

LRO hardware/site imagery was not called singular proof, and individual bootprints were not claimed to be directly resolved at ~0.5 m/pixel.

### Executable v0.3 enforcement
`NOT_TESTED`

The correction still depended on human challenge and manual application of OGI rules rather than an implemented runtime preventing `EXPLANATION_PRELOAD` automatically.

## Candidate lessons

### `EXPLANATION_PRELOAD`
A causal explanation is supplied before the evidentiary state of its antecedent proposition has been adjudicated.

### `CAPABILITY_EQUIVOCATION`
Loss of one production architecture is treated as loss of the underlying capability.

### `INDEPENDENCE_COMPRESSION`
Multiple artifacts or analyses from a shared institutional pipeline are incorrectly counted as independent confirmations.

### `ALTERNATIVE_MODEL_BURDEN`
An alternative model must explain the joint evidence field rather than only one anomaly, while the conventional model remains equally responsible for explaining anomalies that genuinely survive.

## Strongest OGI finding

> **The failure was caught before merge, not after publication. That is exactly what the branch-return architecture is for. But a future executable OGI should catch `EXPLANATION_PRELOAD` without requiring the human researcher to notice it first.**
