## Human research event (subject ledger)

Sean Diamond selected and briefly inspected a previously unfamiliar small grey cuneiform tablet, then supplied a *human-led* sequential reading using a horizontally mirrored, transparent image translated over the original. The author reports not knowing the catalogue interpretation when beginning. The conversation preserved seven frames, C1001 → C1002 → C1003 → (return to missed intermediate C1002A) → C1004 → C1005 → C1006. For publication / reading order C1002A sits between C1002 and C1003, while the actual **discovery chronology** includes returning backwards after C1003.

The claimant's interpreted sequence is formally preserved as a primary *reading record*: experienced listening operator / purpose; librarian and information transfer; military instructor and actively engaged student; linga and tabernacle formation; maturation; graduation; work with people, animals and community. The report retains uncertainties and does not infer original scribal intent merely from coherence.

**Recovered original artifact AFTER the reading:** Metropolitan Museum of Art **11.217.19**, *Cuneiform tablet: receipt of lambs*, Ur III Neo-Sumerian, ca. 2041 BCE, Drehem (Puzrish-Dagan), https://www.metmuseum.org/art/collection/search/322463 . It is distinct from Met 11.217.18 (*receipt of an ox and lambs*).

**Recovered working settings:** Microsoft Excel, horizontal image flip, **58% transparency**, reflected layer placed on the **right**, moved **right to left**. Original per-frame offsets, source image hash and workbook remain unavailable.

## OGI method ledger: what this case demonstrates

1. **Available memory / prior-work return:** The researcher requested reaccessing Court's earlier cuneiform challenge. The GitHub audit `research-spine/02-cuneiform-visible-derivation-audit.md` and earlier COP / OGI case material already existed. Repeating 'plenty of accounting tablets' without returning to these records omitted material scope; earlier challenges are not to be erased or reinvented.
2. **Artifact identity acquisition:** Initially a tablet image was present but its accession unknown; after the reading the user supplied museum screenshot; Met catalogue identifies **11.217.19**. This is an actual manual provenance improvement, not evidence that OGI autonomous memory is implemented.
3. **Method-parameter recovery:** An initial report recorded a mirrored overlay with unspecified settings; human later supplied Excel / horizontal flip / 58% transparency / right-to-left trajectory. The report was reissued without changing the underlying reading. This is **constructive return** as a documented human–AI workflow.
4. **Sequence versus discovery chronology:** The intermediate C1002A was found by returning backward; the displayed correct sequence differs from discovery order. OGI should preserve both rather than presenting a fictional straight-through reading.
5. **Institutional-label comparison:** Met calls the artifact a 'receipt of lambs'; the claimant reports not identifying a lamb within the image-first overlay. This is a **new competing account anchor**, not a verdict that one interpretation has been proven or falsified.
6. **Representation and completion:** The Word/PDF illustrated report contains all seven original image plates. The GitHub case text and metadata are on review branch, while the PDF and DOCX files remain current-conversation artifacts unless uploaded separately. A model claiming GitHub holds the illustrations before binary ingestion would repeat an exhibit-substitution failure.
