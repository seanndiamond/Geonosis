# OGI derivation: v0.3.1 → v0.3.2

**11 November 2026 | EXTENSION / PROPOSED**

## Inherited state
v0.3.1 specifies Human Participant, Question Premise Audit, Self-Intervention Protocol, Evidence-State Lock and Explanation-to-Exhibit Gate; several controls remain specification-level.

## New observations
1. The *Intelligence Is Not a Ladder* research programme and book repeatedly recovered older visual research, behavioural observations, corrections and documents across separate sessions.
2. The Court and OGI have preserved versioned state and case findings with cross-project returns.
3. In the November Linear B dialogue, a model repeatedly substituted conventional translations and standard glyphs for a requested artifact-to-sign demonstration; the user prompted the crucial correction.
4. Memory need not mean that all historical content occupies active model context. Relevance-linked access to retained records can enable continuity.
5. Retrieval-on-demand suggests a possible resource-efficiency advantage but no measured savings yet exist for OGI.

## Derivation to controls
- (1,2,4) → Available Memory and Relational Continuity Layer; explicit stored / available / retrieved / inspected / active states.
- (1,2) → dependency graph and constructive return, beyond error recovery alone.
- (3) → executable artifact-to-representation gate and task-substitution self-intervention.
- (5) → total-cost/quality benchmark, not an efficiency claim.

## Invariants retained
Court of Provenance is the sole canonical adjudication system. Current warranted state is not replaced by a convenient memory summary. Permission, human authorisation, safe exit, independence accounting and explicit state transitions still govern.

## What this does not prove
- That the full OGI architecture is operational or AGI.
- That retrieval is always cheaper, faster or more reliable.
- That Linear B lacks phonetic writing.
- That the alternative pictorial readings in the dialogue are independently validated.
- That this observed partnership has already outperformed matched controls.

## Reopen conditions
Benchmark failure, security/privacy failure, stale retrieval promoted as current state, false graphic matching, user-agency erosion, or a simpler superior approach.

## Status
Proposal registered for engineering implementation and adversarial test. Do not update the previous specification in place or mark proposed components as implemented.
