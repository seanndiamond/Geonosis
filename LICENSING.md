# Licensing and Reuse Boundary

The Geonosis repository contains more than one class of material: research writing, data structures, code/tooling, diagrams, photographs, source images, annotations, quotations and third-party material.

A single blanket licence is therefore not assumed for every asset.

## Existing repository licence

The repository contains a `LICENSE` file using the GNU General Public License v3.0.

For the purposes of this project, that licence is intended to govern **software and source code that is explicitly released under it**.

## Research texts and original scholarly material

Unless an individual file states another licence, research papers, prose, original diagrams, annotations and scholarly compilations by Sean Diamond remain **copyright Sean Diamond** and are made publicly readable for research, criticism, quotation, verification and discussion.

No broader relicensing or commercial reuse permission should be inferred solely from the presence of the software licence.

A Creative Commons licence may be added later to specific research outputs once the author has selected the intended reuse terms.

## Third-party images and sources

Third-party material retains its original rights status.

The archive should record:

- creator/custodian;
- source;
- licence or reuse basis where known;
- whether an image is reproduced, linked, quoted, transformed or used only as a provenance reference.

Public availability does not equal public-domain status.

## Indigenous and heritage-sensitive material

Legal permission is not the only consideration. Cultural sensitivity, community authority, restricted knowledge, precise site coordinates and heritage risk may require withholding or limiting material even where a technical right to republish might otherwise exist.

## Data and schemas

Machine-readable schemas created specifically for reproducibility may later be given an explicit open-data or permissive licence. Until then, reuse should retain attribution and provenance.

## Plain-language rule

**Open the doorway without pretending every object in the workshop has the same ownership label.**

This file is a project policy statement, not legal advice.
