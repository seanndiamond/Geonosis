## Status language

Preferred public states:

- `open_observation`
- `under_test`
- `provisional_pass`
- `pass`
- `fail`
- `inconclusive`
- `superseded`
- `withdrawn`

A `fail` is not removed. It becomes part of the method record.

## The most important immediate empirical test

For the Taş Tepeler operator grammar, the project itself identifies the key question:

> Can independent observers who have not seen the author's readings map the same operator categories from the source images and plans?

That test should be designed before adding more interpretive altitude.
