# Geonosis

## A reproducible public research archive for reading field before form

**Sean Diamond — Independent Researcher, Geonosis Project / GlyphLens R&D**

> **Observe first. Map relations. Test constraints. Then interpret.**

Geonosis is an independent research programme for testing whether visual, spatial, archaeological, biological and terrain-based systems can preserve structured information through relation, recurrence, placement, boundary, sequence and form.

The project uses **Méthodê Glyph** as its formal constraint-first visual method and **Picterpretation** as the disciplined act of treating images as primary epistemic artefacts rather than merely as illustrations of inherited textual explanations.

This repository is being built as the **public audit trail of the work**, not merely a gallery of conclusions.

## Visible derivation standard

Where relevant, a consequential claim should expose:

- the original artefact, site, image, dataset or source field;
- the exact visible mark, feature, relation or location;
- source provenance and viewing conditions;
- transformations such as crop, rotation, contrast, overlay or AI processing;
- identification of the visible unit;
- plausible alternative identifications or values;
- the reason one interpretation is selected;
- transliteration or technical classification where applicable;
- grammatical, operational, spatial or construction steps;
- controls and negative examples;
- prediction where possible;
- explicit failure conditions;
- independent reproduction attempts;
- external technical validation where the claim requires it.

**A citation shows that a claim was made. It does not by itself show how the claim was derived from the field.**

## Evidence rooms

The repository separates claims instead of blending them into one persuasive paragraph:

| Room | Example |
|---|---|
| Source | The artefact/image/site/document exists and is correctly identified. |
| Observation | A feature is visibly present or absent. |
| Operator | A constrained functional relation is proposed. |
| Grammar | Operators form a local sequence/system. |
| Recurrence | The grammar repeats across comparable cases. |
| Prediction | The model forecasts unseen evidence before inspection. |
| Reproduction | Independent observers recover the central mapping. |
| External validation | Domain testing supports the specific proposition tested. |
| Reconstruction | Historical/civilisational process is proposed. |
| Speculative extension | Metaphysical, consciousness-field or cosmological interpretation. |

The rooms communicate. They do not quietly collapse.

## Core research laws

- **Field before form.** Read relation before category.
- **Method before claim.** The path to the conclusion matters more than its grandeur.
- **A caption is not a translation. A classification is not an audit.**
- **Constraint first.** If nothing constrains, nothing proceeds.
- **No isolated system reading.** One attractive shape cannot carry an executable grammar.
- **Equal evidentiary rule.** Conventional and unconventional models face the same source burden.
- **Failure must be possible.** A model that cannot lose cannot earn confidence.
- **Corrections are additive.** Earlier records remain visible.
- **Tools test; they do not decide.** AI is an audit partner, not an oracle.
- **Geonosis accepts the scrutiny it requests.**

## Public-release boundary

This is an open research doorway, not an indiscriminate dump of every private working file.

Material may remain outside the public repository where it contains unresolved rights, private information, heritage-sensitive coordinates, incomplete provenance or unpublished working material whose status would be distorted by public release.

Canonical source records are fingerprinted in [`archive/canonical/SOURCE_RECORDS.md`](archive/canonical/SOURCE_RECORDS.md).
